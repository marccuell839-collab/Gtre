# Bounty Workbench

> **تطبيق Android الأصلي:** المشروع في [android/](android/)، مبني بـ Kotlin وC++ مع واجهة عربية زجاجية. نزّل APK بعد نجاح البناء من [Releases](https://github.com/marccuell839-collab/Gtre/releases) أو تابع [GitHub Actions](https://github.com/marccuell839-collab/Gtre/actions/workflows/android.yml). اقرأ [دليل Android](android/README.md) للقدرات والحدود.

> الملفات في جذر المستودع أدناه هي النسخة السابقة للويب المحلي، وليست مطلوبة لتشغيل APK.

نسخة أولى محلية بواجهة عربية لإدارة تقييمات أمنية محدودة ومصرّح بها. ليست منصة استغلال شاملة، ولا تدّعي تعويض المراجعة البشرية أو كشف كل الثغرات.

## التشغيل

يتطلب Python 3.10 أو أحدث؛ التطبيق نفسه يستخدم المكتبة القياسية فقط ولا يحتاج pip.

```sh
python3 app.py
```

افتح `http://127.0.0.1:8765` وأدخل رمز الجلسة الذي يظهر في الطرفية. الرمز يتغير عند كل تشغيل ولا يُحفظ في المتصفح. يعمل على Windows وLinux، وعلى Termux إذا كان Python متوفرًا. لا تفتح المنفذ على الإنترنت.

## الوظائف المتاحة

- تسجيل مرجع البرنامج والقواعد والتصريح قبل التنفيذ.
- أصل واحد دقيق لكل تقييم مع تأكيد الرابط يدويًا؛ لا زحف أو توسيع نطاق.
- طلب HTTP HEAD واحد لرصد الرؤوس دون جلب جسم الصفحة، أو متابعة التحويلات، أو إعادة المحاولة.
- Nmap اختياري: فحص TCP connect لمنفذ الرابط الواحد، دون NSE أو استغلال أو كشف إصدارات.
- مراجعة استدلالية لنص SQL محلي؛ لا تنفيذ للكود ولا تشغيل sqlmap.
- سجل SQLite محلي، حفظ الأدلة المختصرة، وتنزيل تقارير Markdown للمراجعة والإرسال اليدوي.
- رمز جلسة، تحقق Origin وHost لواجهات API، منع العناوين الخاصة والمختلطة، وتثبيت الاتصال على IP المتحقق منه لمنع إعادة ربط DNS.

## حدود مهمة

القواعد النصية لا تُفسَّر تلقائيًا إلى استثناءات قابلة للتنفيذ. يجب على الباحث التأكد من أن الرابط والأسلوب يوافقان قواعد البرنامج قبل تحديد مربع التصريح. دعم النطاق الحالي هو رابط واحد دقيق، ولا يشمل قوائم نطاقات أو wildcards. Nmap يحتاج تصريحًا صريحًا للـ IP والمنفذ، خصوصًا خلف الاستضافة المشتركة وCDN؛ امتلاك نطاق لا يكفي.

Nmap غير مثبت تلقائيًا. راجع تثبيته وموافقاتك في بيئتك بصورة منفصلة إذا احتجته. المهمة تتوقف إذا لم تجده. مسح المنافذ ليس طلب HTTP؛ قد يولد عدة حزم رغم اقتصاره على منفذ واحد. المهلة القصوى 25 ثانية وبدون إعادة إرسال على مستوى Nmap. HTTP يتوقف عند 429 و5xx؛ مهمة واحدة تعمل في نفس الوقت.

النتائج لا تُصنَّف مؤكدة تلقائيًا. غياب رأس أمان أو وجود منفذ مفتوح ليس وحده ثغرة. فاحص SQL محدود وقد يفوّت أخطاء أو يرفع اشتباهات غير صحيحة. تقارير هذه النسخة أولية وتحتاج إضافة تحقق وأثر فعليين يدويًا. لا تُحفظ شفرة SQL المرسلة، لكن قواعد البرنامج وبيانات التقييم تبقى في `data/` دون تشفير؛ لا تدخل أسرارًا أو بيانات مستخدمين. لا ترفع هذا المجلد إلى GitHub.

## الاختبارات

```sh
python3 -m unittest discover -s tests -v
```

الاختبارات تستعمل بدائل محلية للشبكة وNmap؛ لا تختبر أهدافًا خارجية. تكامل Nmap الفعلي يتطلب وجود الأداة وهدفًا مصرحًا به ولم يُختبر في بيئة الإنشاء.

## الهيكل

`app.py`: خدمة محلية ومصادقة وسجل. `engine.py`: الفحوص والتقرير. `web/`: الواجهة العربية. `tests/`: اختبارات حدود الأمان والسلوك.
