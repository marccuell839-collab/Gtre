# Bounty Workbench · Android

تطبيق Android أصلي بـ Kotlin وC++ عبر JNI، وليس WebView أو واجهة Termux. Android 8.0 فأحدث؛ ARM64 وARMv7 وx86_64. لا يحتاج Root أو Python أو صلاحيات تخزين شاملة.

## الوظائف

- واجهة عربية RTL، بطاقات شفافة متدرجة بتأثير زجاجي، خلفية Aurora وانتقالات مخففة عند تعطيل الحركة بالنظام.
- إعداد البرنامج والقواعد ورابط واحد مسموح وقائمة استثناءات دقيقة. الاستثناءات تتقدم على السماح.
- HTTP HEAD واحد مع TLS والتحقق من الشهادة والمضيف، وحدود للمهلة وحجم الرؤوس، دون تحويلات أو جسم صفحة.
- اتصال TCP أصلي C++ بمنفذ واحد مصرح به، بلا payload أو كشف إصدارات. ليس Nmap.
- تحليل SQL محلي C++ استدلالي، دون تنفيذ الكود أو sqlmap.
- سجل آخر 100 تقييم محليًا، تقارير Markdown، حفظ عبر منتقي Android ومشاركة يدوية.

لا Nmap أو sqlmap أو مسح شامل أو استغلال تلقائي داخل هذا الإصدار. لا تُصنّف الملاحظات مؤكدّة دون تحقق يدوي. إعداد القواعد النصية لا يعني أن التطبيق فهمها؛ يجب مراجعتها قبل تأكيد الخطة. لا يستخدم DNS لتوسيع نطاق الأهداف، ويتصل بالعنوان المتحقق منه فقط. يمنع العناوين الخاصة والمحجوزة الشائعة وDNS المختلط. فحص TCP يتطلب تصريح IP والمنفذ؛ تصريح اسم نطاق خلف CDN لا يكفي.

## APK عبر GitHub Actions

افتح تبويب Actions ثم Android APK. البناء يعمل عند تغييرات android أو ملف workflow على main، ويمكن تشغيله يدويًا. بعد نجاح البناء يوجد APK في Artifact باسم Bounty-Workbench-APK، وفي Releases كملف مباشر Bounty-Workbench.apk مع SHA256SUMS.txt.

APK موقّع بمفتاح debug للتجربة الشخصية، وليس إصدار متجر بمفتاح إصدار دائم. مفتاح CI قد يختلف بين البنايات؛ إذا رفض Android التحديث قد تحتاج إزالة النسخة القديمة، مما يحذف سجلها؛ صدّر تقاريرك أولًا. لا توجد آلية تحديث آلية أو تشفير مستقل لسجل التطبيق؛ التخزين داخلي والنسخ الاحتياطي معطّل. حذف التطبيق يمحو بياناته.

## بناء محلي

JDK 17، Gradle 8.9، Android SDK 35، NDK 27.0.12077973، CMake 3.22.1. افتح مجلد android في Android Studio أو شغّل من داخله باستخدام Gradle المثبّت:

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

لا يحتوي المشروع على Gradle wrapper؛ GitHub Actions يوفّر نسخة Gradle المحددة. اختبارات النطاق محلية، والاختبارات الأصلية تفحص SQL دون شبكة. اختبار تشغيل APK على جهاز فعلي منفصل عن نجاح البناء، ولا يجري CI فحوصًا على مواقع خارجية.
